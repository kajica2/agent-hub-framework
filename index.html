Quick start

git clone https://github.com/kajica2/agent-hub-framework.git
cd agent-hub-framework
npm install
npm run validate    # schema + paywall gate
npm run build       # paywall-gated dist/ output
npm run loop        # one rotation of the long-horizon supervisor

What's in here

schema/

JSON Schemas. Project, channel, capability taxonomy (closed vocabulary).

scripts/

validate.mjs (gate), build.mjs (paywall partition), capture-screenshots.mjs.

loop/

supervisor.mjs — round-robin orchestrator with termination + cooling-off.

watchdog/

One-step relay. Telegram + iMessage bridge. End-of-rope hand-off.

plans/

long-horizon.md — 3-year / 12-month / 90-day / this-month horizons.

examples/

Forkable templates. projects.example.json (24 entries), agents.example.json (8 personas).

components/

Component library scaffold. framework-owned, cross-linked from projects.

.github/workflows/

loop.yml (5-min cron + per-push), watchdog.yml (8h heartbeat + done/stuck triggers).

The paywall discipline

Project entries with material_license.kind ∈ {internal-paywalled, licensed-restricted, private} are never written to public output. The build script (scripts/build.mjs) exits with code 1 on any leak attempt. Bob Mover lexicon, Serious Fun, Jazzability are examples of internal-paywalled content that the build script correctly filters out of public-side artifacts.
